🧪 These days I'm building and experimenting with different kinds of software, mostly to answer one question:

> **What happens when software becomes cheap, custom and on-demand?**

🦖 Most small and medium businesses run on expensive, one-size-fits-all legacy software. It does half of what they need, and they pay far more for it than they should in 2026.

🤖 I think AI changes that. I'm interested in:
- Companies **replacing legacy software with AI-built tools**
- **Custom software for SMBs** and non-tech businesses: tools built around how they actually work, not the other way around
- The shift from **off-the-shelf → custom**, **expensive → cheap**, **closed → open source**
- Helping non-tech companies get **leaner and more efficient** without needing an engineering team

💳 I'm still into payments and ecommerce, where a lot of these dinosaurs live.
